A
সবচেয়ে সহজ: Drag & Drop
সুপারিশকৃত • ৩০ সেকেন্ড
  1. 1.এই পেজে Ctrl+S চাপুন → ফাইলের নাম দিন index.html → Desktop-এ সেভ করুন।
  2. 2.যান app.netlify.com/drop → Netlify অ্যাকাউন্টে লগইন করুন (GitHub/Google দিয়ে ফ্রি)।
  3. 3.index.html ফাইলটি টেনে Drop জোনে ছাড়ুন → ২০ সেকেন্ডে লাইভ! যেমন: amar-space.netlify.app
  4. 4.নাম বদলাতে: Site Settings → Change site name।
B
প্রো উপায়: GitHub + Auto Deploy
আপডেট করলেই অটো লাইভ
  1. 1.GitHub-এ নতুন repo বানান (যেমন amar-space) → index.html আপলোড করুন।
  2. 2.Netlify → Add new site → Import from Git → repo সিলেক্ট করুন।
  3. 3.Build settings খালি রাখুন (Publish directory: .) → Deploy।
  4. 4.এরপর GitHub-এ ফাইল বদলালেই সাইট অটো-আপডেট হবে।

netlify.toml — কপি করে প্রজেক্টে রাখুন (ঐচ্ছিক কিন্তু সেরা)

[build]
  publish = "."

[[headers]]
  for = "/*"
  [headers.values]
    X-Frame-Options = "DENY"
    X-Content-Type-Options = "nosniff"
    Referrer-Policy = "strict-origin-when-cross-origin"
    Cache-Control = "public, max-age=3600"

[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200
